# Astrophysical Phase Space Dynamics

Measuring two things from the Milky Way's vertical phase space (z, w):

- the **scale height of the dark-matter halo**, `h_dm`, and
- the **dynamical time of the phase-space spiral**, Δt (the time since the disk was perturbed).

Pipeline: data → normalizing-flow model of the initial distribution f₀ →
differentiable Hamiltonian back-integration → joint maximum likelihood in (h_dm, Δt).

## Layout

| Path | What |
|------|------|
| `fitter.py` | Core physics + flows: potentials, leapfrog back-integration, MLE fitters |
| `phase_space_simulation.py` | Forward simulation of mock data |
| `experiments/` | Experiment package (`common.py` = shared machinery, `exp_*.py` = tests, `run_*.py` = long runs) — see `INDEX.md` |
| `experiments/hyperopt_cluster.py` | Shardable / resumable cluster study of the (h_dm, Δt) fitter |
| `experiments/slurm/` | SLURM array script for `hyperopt_cluster` |
| `cluster/` | Cluster setup (`setup_env.sh`) and a generic one-job script (`run_script.sbatch`) |
| `NF_hdm_fit__*.ipynb` | Thin notebooks that drive / plot the experiments |
| `*.tex`, `overleaf/` | Notes and derivations |
| `results/` | Cached results — **not tracked** (except small `.json` summaries); regenerated by the runs |

## Local setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m experiments index        # regenerate INDEX.md
```

## Running on the cluster

```bash
# once, on a login node
git clone git@github.com:<user>/<repo>.git
cd <repo>
bash cluster/setup_env.sh           # creates .venv with CPU torch, checks imports

# always run the smoke test first, then look at the cost estimate
source .venv/bin/activate
python -m experiments.hyperopt_cluster smoke
python -m experiments.hyperopt_cluster plan search

# array job (resumable: just resubmit the same line after a timeout)
sbatch --array=0-63 experiments/slurm/hyperopt_array.sbatch search
python -m experiments.hyperopt_cluster merge  search
python -m experiments.hyperopt_cluster report search

# any single script
sbatch cluster/run_script.sbatch experiments/run_mirror_fit.py 2w 16
```

Logs go to `logs/`. Memory, not cores, is the limit: one fit needs
~0.5 GB + 33 kB per star (≈1.2 GB at N = 2·10⁴, 3.8 GB at N = 10⁵).

### Moving code and results

- Code: `git push` on the laptop, `git pull` on the cluster (and the reverse for
  any edits made there).
- Results are not in git. Copy them with e.g.
  `rsync -av <cluster>:<repo>/results/ results/`.
